# Security incident response

1. **Detect and classify:** Record time, source, affected systems, and suspected data categories without copying sensitive payloads into chat or tickets.
2. **Contain:** Revoke sessions/devices, rotate exposed credentials, block malicious traffic, and preserve evidence.
3. **Assess:** Determine tenants, records, processors, and jurisdictions affected.
4. **Notify internally:** Assign incident commander, security lead, privacy lead, engineering lead, and communications owner.
5. **Legal and regulatory review:** Assess Ghana Data Protection Commission and affected-person notification duties without avoidable delay.
6. **Recover:** Restore integrity, validate RLS, rotate keys, and monitor for recurrence.
7. **Review:** Document root cause, control failure, corrective actions, owners, and deadlines.

Do not promise that an incident is resolved until containment and integrity verification both pass.
